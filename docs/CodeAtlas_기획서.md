## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | **CodeAtlas** (접수 정보 기준으로 통일. 개발 중 "PaperBridge"라는 명칭이 문서에 혼용됐으나 공식 등록명인 CodeAtlas로 최종 확정) |
| 참가 부문 | 자유과제 — 인공지능(AI) 분야 |
| 기술 방향 참고 | 리원에이스 지정과제(AI 에이전트·NL2SQL·pgvector·Spring AI MCP) 방향을 자유과제로 재구성 |
| 팀 구성 | 2인 팀 (팀원 A: Knowledge Retrieval Engineer / 팀원 B: Agent & AI Product Engineer) |

### 개발 목적 (기존 접수 내용 유지)

> 논문 속 핵심 설명과 공개 GitHub 구현 코드를 연결하여 연구자와 개발자가 알고리즘 구현 위치를 빠르게 찾고 재사용할 수 있는 오픈소스 개발 지원 도구를 개발한다.

### 프로젝트 소개 (수정본 — 사실관계 정정)

> **변경 사유**: 기존 문구의 "Papers With Code의 GitHub 저장소를 수집"이라는 표현은 (1) Papers with Code가 2025년 7월 서비스 종료된 상태이고 (2) 실제로는 자동 수집이 아닌 팀원 A의 수동 큐레이션 방식이라는 점에서 두 가지 모두 사실과 달라 수정함.

> CodeAtlas는 arXiv 논문과 그에 대응하는 GitHub 오픈소스 구현체를 직접 선별·수집하고, 논문 섹션과 코드 블록을 pgvector 기반 유사도 검색으로 매핑하는 웹 플랫폼이다. MCP 에이전트가 논문 검색, 코드 탐색, 수식 및 구현 위치 확인을 병렬 수행하며, 사용자는 PDF 뷰어와 코드 하이라이터를 통해 근거를 확인한다.

### 기대 효과 (기존 접수 내용 유지)

> 본 프로젝트는 논문 이해와 구현 탐색에 드는 시간을 줄이고, 연구 결과의 재현성과 오픈소스 코드 재사용성을 높인다. 개발자는 특정 모델 구조나 수식이 실제 코드 어디에 구현되어 있는지 빠르게 확인할 수 있고, 연구자는 기존 구현을 비교하여 실험 출발점을 확보할 수 있다. 또한 MCP 기반 병렬 도구 호출, pgvector 하이브리드 검색, NL2SQL 질의 기능을 오픈소스로 제공하여 다른 연구 문서, 기술 문서, 코드베이스 분석 도구로 확장 가능한 개발자 생태계 인프라를 구축한다.
