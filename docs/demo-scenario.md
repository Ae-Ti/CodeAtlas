# 데모 시나리오 — 시연영상(3분) 대본 겸용

> [#9](https://github.com/Ae-Ti/CodeAtlas/issues/9) · 기획서 §5 3주차 완료 기준 "3개 데모 시나리오 안정 시연" · 2차 평가 **작품 데모 10점** 직결
> 작성: B (Taeil Bae)

논문 9편이 확보돼(#7) **논문 1편당 시나리오 1개** 구성이 가능해졌고, 동시에 각
시나리오가 서로 다른 기능 축을 보여주도록 배치했다 — 같은 화면을 세 번 보여주는
3분짜리 영상은 심사위원에게 기능이 하나뿐이라는 인상을 준다.

| # | 논문 | 기능 축 | 시간 |
|---|---|---|---|
| 0 | — | 인트로: 문제 정의 + 카탈로그 규모 | 0:00–0:15 |
| 1 | Attention Is All You Need | 단락 → 코드 매핑 + AI 근거 (핵심 기능) | 0:15–1:15 |
| 2 | Segment Anything | MCP Agent 자연어 질의 + TACC 퍼널 | 1:15–2:10 |
| 3 | 카탈로그 전체 | NL2SQL + 연결 그래프 | 2:10–2:50 |
| — | — | 마무리: 확장 방향 한 문장 | 2:50–3:00 |

⚠️ **chunk id를 대본에 적지 않는다.** id는 적재 이력에 따라 달라진다 — smoke.sh가
chunk 101을 하드코딩했다가 seed_dump 복원본에서 깨진 것과 같은 함정([#27](https://github.com/Ae-Ti/CodeAtlas/pull/27)).
아래 동선은 전부 **화면에 보이는 섹션 제목**으로 적는다.

## 시나리오 0 — 인트로 (15초)

**화면**: Dashboard (`/`)

> "논문을 읽다가 '이 수식이 코드로는 어디에 있지?'를 찾는 데 시간이 갑니다.
> CodeAtlas는 arXiv 논문 단락과 GitHub 구현 코드를 미리 연결해 둔 플랫폼입니다.
> 지금 논문 9편, 저장소 12곳, 단락 376개, 코드 블록 183개가 들어 있습니다."

**화면에 나와야 할 수치**: Dashboard 통계 카드 — 논문 9 / 저장소 12 / chunk 376.
수치가 다르면 DB가 seed_dump 최종본이 아니라는 뜻이니 시연을 멈추고 복원부터.

## 시나리오 1 — 단락→코드 매핑 (Attention Is All You Need, 60초)

핵심 기능이라 가장 길게. **말로 설명하지 말고 클릭 동선이 스스로 말하게 한다.**

| 단계 | 클릭 | 화면에 나와야 할 것 |
|---|---|---|
| 1-1 | 논문 목록 → **Attention Is All You Need** | chunk 목록 (63개) |
| 1-2 | 좌측 목차에서 **"3.2.2 Multi-Head Attention"** 클릭 | 우측에 Code Implementations **5건**, 1위 `transformer/SubLayers.py`의 `MultiHeadAttention.forward` (유사도 ~0.70) |
| 1-3 | "1위 매칭 근거" 카드 | **`precomputed` 배지(초록)** + Qwen3가 생성한 한국어 설명. 이 응답이 **즉시(5~25ms)** 온다는 것을 말로 짚는다 |
| 1-4 | 1위 코드 클릭 | Monaco 뷰어가 해당 파일을 열고 **매칭 줄(30행 부근) 하이라이트** |
| 1-5 | 원문 링크 클릭 (선택) | GitHub 의 같은 파일·같은 줄로 이동 — "근거를 끝까지 검증할 수 있다" |

> 대사 예시: "multi-head attention 단락을 클릭하면, 이 논문의 공식 구현 저장소
> 안에서 대응 코드 5개를 보여줍니다. 1위는 사람이 검수한 매핑이고, AI 설명은
> 미리 계산돼 있어 바로 뜹니다. 코드를 클릭하면 해당 줄이 하이라이트되고,
> GitHub 원본으로 검증까지 갈 수 있습니다."

**여기서 검색 품질 수치를 언급** (결과보고서와 같은 표현으로 — "개선"이 아니라 "교정"):
"논문 범위 안에서 Top-5 65.4%, 사람이 후보 5개 중 고르는 전제입니다."

## 시나리오 2 — MCP Agent 자연어 질의 (Segment Anything, 55초)

| 단계 | 클릭 | 화면에 나와야 할 것 |
|---|---|---|
| 2-1 | 상단 메뉴 → **Agent** (`/agent`) | 질의 입력창 + 예시 질문 버튼 |
| 2-2 | 입력: **"SAM의 mask decoder는 코드로 어떻게 구현됐어?"** | MCP tool 카드가 순서대로 done 처리되는 타임라인 (SearchPaperChunk → FindCodeImplementation → …) |
| 2-3 | 결과 카드 | 매칭된 SAM 단락("Mask Decoder Overview" 계열) + 코드 후보 + TACC 요약("후보 N개 중 제외 M개 → 5개 선택") |
| 2-4 | `precomputed` 배지 짚기 | "무거운 생성은 큐레이션 때 한 번, 조회는 즉시" |

> 대사 예시: "화면을 벗어나서, 자연어로 바로 물을 수도 있습니다. MCP tool 4종이
> 검색→코드매칭→컨텍스트 선별을 순서대로 수행하고, TACC가 후보를 걸러낸 근거를
> 그대로 보여줍니다."

**리허설에서 확정할 것**: 위 질의가 SAM 단락을 1위로 물어오는지. 아니면
`darknet`·`vision_transformer` 등과 섞일 수 있다 — 리허설에서 실제 1위 chunk를
확인하고 **대본의 질의 문구를 그 결과에 맞춰 고정**한다. (질의→chunk 매칭은
전체 코퍼스 대상 벡터 검색이라 문구에 민감하다)

## 시나리오 3 — NL2SQL + 연결 그래프 (40초)

| 단계 | 클릭 | 화면에 나와야 할 것 |
|---|---|---|
| 3-1 | Agent 페이지 하단 **NL2SQL** 섹션 | 예시 버튼 3개 |
| 3-2 | 예시 버튼 **"star 수 상위 3개 repository 알려줘"** 클릭 | **생성된 SQL 원문** + 결과 행. "SQL을 숨기지 않고 보여준다 — 검증 가능성" |
| 3-3 | 상단 메뉴 → **Graph** (`/graph`) | 논문↔저장소↔코드 연결 그래프. 마우스로 한 논문 클러스터 확대 |

> 대사 예시: "메타데이터는 자연어로 SQL을 생성해 조회하고 — 생성된 SQL을 그대로
> 노출해 검증할 수 있습니다 — 카탈로그 전체의 논문-코드 연결은 그래프로 조망합니다."

## 시연 전 점검 (당일 아침, 순서대로)

```bash
./scripts/doctor.sh                          # 1. Ollama·DB·백엔드 환경
docker exec -i codeatlas-postgres psql -U codeatlas -d codeatlas \
    -tAc "SELECT count(*) FROM papers"       # 2. = 9 인지 (seed_dump 최종본)
curl -s -X POST localhost:8080/api/admin/curate-pending   # 3. pending 0건 확인
./scripts/smoke.sh                           # 4. 8/8 통과
```

3번이 핵심이다 — **pending이 남아 있으면 그 chunk는 시연 중 라이브 폴백으로
16~27초를 기다린다.** `chunksPending: 0` 응답을 확인해야 시연 전 준비가 끝난 것.

| 리스크 | 증상 | 대응 |
|---|---|---|
| 미큐레이션 chunk를 클릭 | "1위 매칭 근거"가 수십 초 로딩 | 위 3번으로 사전 차단. 그래도 발생하면 배지가 `live`로 뜨는 것을 "신규 논문도 그 자리에서 동작한다"로 살려서 진행 — [#29](https://github.com/Ae-Ti/CodeAtlas/pull/29) 이후 같은 chunk 재클릭은 즉시 응답 |
| Ollama 다운 | NL2SQL·live 경로 에러 | 시나리오 1은 precomputed라 Ollama 없이도 동작. 시나리오 3을 건너뛰고 1-5(원문 링크)를 늘린다 |
| 질의가 엉뚱한 논문 매칭 | 시나리오 2에서 SAM이 아닌 chunk | 리허설에서 문구 고정. 당일 변형 금지 — **대본의 질의를 글자 그대로 입력** |
| 네트워크 없음 (원문 링크) | GitHub 이동 실패 | 1-5는 "선택"이므로 생략하고 Monaco 하이라이트로 마무리 |

## 시연영상(#10) 촬영 메모

- 해상도 1920×1080, 브라우저 전체화면(F11), 북마크바 숨김
- 시나리오 사이 전환은 상단 메뉴 클릭으로 — 주소창 직접 입력은 편집점이 생긴다
- 마우스 이동을 느리게. 하이라이트된 줄에서 1초 이상 머물기
- 각 시나리오를 별도 테이크로 찍고 이어붙인다 — 한 번에 3분을 무결점으로 가려다
  전체를 반복하게 된다
