## 논문 핵심 텍스트

> We train a neural network to predict the correct caption for an image.
> 

> The model learns a joint embedding space for images and text.
> 

---

## 구현 목적

CLIP은 이미지와 텍스트를 각각 Encoder에 넣어서 같은 Feature Space로 변환한다.

전체 구조:

```
                 Image
                   |
                   v
            Image Encoder
                   |
                   v
          Image Embedding Vector
                   |
                   |
             Similarity
                   |
                   |
          Text Embedding Vector
                   ^
                   |
            Text Encoder
                   ^
                   |
                Text
```

핵심 구성:

1. Image Encoder
2. Text Encoder
3. Projection Layer
4. Contrastive Learning

```

```

Text Encoder 연결:

```
self.transformer

---

Forward:

```
def forward(
    self,
    image,
    text
):

    image_features = self.encode_image(image)

    text_features = self.encode_text(text)

    image_features = image_features / image_features.norm(
        dim=-1,
        keepdim=True
    )

    text_features = text_features / text_features.norm(
        dim=-1,
        keepdim=True
    )

    logit_scale = self.logit_scale.exp()

    logits_per_image = (
        logit_scale *
        image_features @ text_features.t()
    )

    logits_per_text = logits_per_image.t()

    return logits_per_image, logits_per_text
```

class Transformer(nn.Module):

    def __init__(
        self,
        width,
        layers,
        heads,
        attn_mask=None
    ):
        super().__init__()

        self.width = width

        self.layers = layers

        self.resblocks = nn.Sequential(
            *[
                ResidualAttentionBlock(
                    width,
                    heads,
                    attn_mask
                )
                for _ in range(layers)
            ]
        )
```

class ResidualAttentionBlock(nn.Module):

    def forward(
        self,
        x
    ):

        x = x + self.attention(
            self.ln_1(x)
        )

        x = x + self.mlp(
            self.ln_2(x)
        )

        return x

## Text Embedding

```
def encode_text(
    self,
    text
):

    x = self.token_embedding(text)

    x = x + self.positional_embedding

    x = self.transformer(x)

    x = x[
        torch.arange(x.shape[0]),
        text.argmax(dim=-1)
    ]

    x = x @ self.text_projection

    return x
```

    logits_per_image,
    ground_truth

    logits_per_text,
    ground_truth
)

loss = (
    loss_i +
    loss_t
