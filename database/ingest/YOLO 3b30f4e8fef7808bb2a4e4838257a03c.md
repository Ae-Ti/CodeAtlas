## 6. 실시간 속도 45 FPS

### 논문 텍스트

> “Our base YOLO model processes images in real-time at 45 frames per second.”
> 

↓

### 대응 코드

공식 저장소에는 특정 GPU에서 반드시 45 FPS를 재현하는 고정 benchmark 함수가 없습니다.

### (예상코드)

```
#include <stdio.h>
#include <time.h>

double benchmark_yolo(
    network *net,
    float *input,
    int iterations
)
{
    clock_t start = clock();

    for (int i = 0; i < iterations; ++i) {
        network_predict(net, input);
    }

    clock_t end = clock();

    double seconds =
        (double)(end - start) / CLOCKS_PER_SEC;

    double fps = iterations / seconds;

    printf(
        "iterations: %d\n"
        "elapsed: %.6f sec\n"
        "FPS: %.3f\n",
        iterations,
        seconds,
        fps
    );

    return fps;
}
```

### 판정

`MISSING-BUT-PROVIDED`

45 FPS는 논문의 실험 결과이며, 저장소 실행 환경에 따라 달라집니다.

## 9. Sliding-window와 R-CNN 설명

### 논문 텍스트

> “DPM use a sliding window approach…”
> 

> “R-CNN use region proposal methods…”
> 

↓

### 대응 코드

공식 YOLO 저장소에는 DPM이나 R-CNN 구현이 없습니다.

### (예상코드)

```
def sliding_window_detector(
    image,
    classifier,
    window_size,
    stride
):
    detections = []

    height, width = image.shape[:2]
    win_w, win_h = window_size

    for y in range(0, height - win_h + 1, stride):
        for x in range(0, width - win_w + 1, stride):
            patch = image[
                y:y + win_h,
                x:x + win_w
            ]

            score, class_id = classifier(patch)

            if score > 0.5:
                detections.append({
                    "x": x,
                    "y": y,
                    "width": win_w,
                    "height": win_h,
                    "score": score,
                    "class_id": class_id
                })

    return detections
```

### 판정

`COMPARISON-METHOD / 예상코드`

이 코드는 YOLO 코드가 아니라 논문에서 비교 대상으로 설명한 sliding-window 방식입니다.

## 22. 24 convolution + 2 fully connected layers

### 논문 텍스트

> “Our network has 24 convolutional layers followed by 2 fully connected layers.”
> 

↓

### 대응 코드

공식 현재 `yolov1.cfg`에는 24개의 convolution 계층이 있지만, 말단은 논문의 두 FC와 정확히 동일하지 않습니다.

```
[local]
size=3
stride=1
pad=1
filters=256
activation=leaky

[dropout]
probability=.5

[connected]
output=1715
activation=linear
```

### 판정

`PARTIAL`

- 24 convolution backbone: 대응
- 논문의 `4096 FC → output FC`: 현재 cfg와 다름
- 현재 cfg: `local → dropout → connected`
- 현재 cfg의 `num=3`, `1715`도 논문의 `num=2`, `1470`과 다름

논문 구조를 정확히 나타내는 예상 구현은 다음과 같습니다.

### (예상코드)

```
import torch
from torch import nn

class YOLOv1Head(nn.Module):
    def __init__(
        self,
        input_features: int = 7 * 7 * 1024,
        hidden_features: int = 4096,
        grid_size: int = 7,
        boxes_per_cell: int = 2,
        classes: int = 20
    ):
        super().__init__()

        output_features = (
            grid_size
            * grid_size
            * (
                classes
                + boxes_per_cell * 5
            )
        )

        self.head = nn.Sequential(
            nn.Flatten(),
            nn.Linear(
                input_features,
                hidden_features
            ),
            nn.LeakyReLU(
                negative_slope=0.1,
                inplace=True
            ),
            nn.Dropout(p=0.5),
            nn.Linear(
                hidden_features,
                output_features
            )
        )

        self.grid_size = grid_size
        self.output_per_cell = (
            classes
            + boxes_per_cell * 5
        )

    def forward(
        self,
        features: torch.Tensor
    ) -> torch.Tensor:
        output = self.head(features)

        return output.view(
            features.shape[0],
            self.grid_size,
            self.grid_size,
            self.output_per_cell
        )
```

## 40. Equation (3) — 전체 YOLO loss

### 논문 텍스트

논문 loss는 다음 다섯 부분입니다.

1. object box의 `x, y` loss
2. object box의 `sqrt(w), sqrt(h)` loss
3. object confidence loss
4. no-object confidence loss
5. object cell의 class loss

↓

### 대응 코드

공식 cfg의 가중치:

```
object_scale=1
noobject_scale=.5
class_scale=1
coord_scale=5
sqrt=1
```

### (예상코드)

```
import torch
from torch import nn

class YOLOv1Loss(nn.Module):
    def __init__(
        self,
        coord_scale: float = 5.0,
        noobject_scale: float = 0.5
    ):
        super().__init__()

        self.coord_scale = coord_scale
        self.noobject_scale = noobject_scale

    def forward(
        self,
        predicted_xy: torch.Tensor,
        predicted_wh: torch.Tensor,
        predicted_confidence: torch.Tensor,
        predicted_classes: torch.Tensor,
        target_xy: torch.Tensor,
        target_wh: torch.Tensor,
        target_confidence: torch.Tensor,
        target_classes: torch.Tensor,
        responsible_mask: torch.Tensor,
        object_cell_mask: torch.Tensor
    ) -> torch.Tensor:
        coordinate_loss = (
            (
                predicted_xy
                - target_xy
            ).pow(2)
            * responsible_mask.unsqueeze(-1)
        ).sum()

        width_height_loss = (
            (
                torch.sign(predicted_wh)
                * torch.sqrt(
                    predicted_wh.abs() + 1e-6
                )
                - torch.sqrt(
                    target_wh.clamp_min(1e-6)
                )
            ).pow(2)
            * responsible_mask.unsqueeze(-1)
        ).sum()

        object_confidence_loss = (
            (
                predicted_confidence
                - target_confidence
            ).pow(2)
            * responsible_mask
        ).sum()

        noobject_mask = (
            1.0 - responsible_mask
        )

        noobject_confidence_loss = (
            predicted_confidence.pow(2)
            * noobject_mask
        ).sum()

        classification_loss = (
            (
                predicted_classes
                - target_classes
            ).pow(2)
            * object_cell_mask.unsqueeze(-1)
        ).sum()

        return (
            self.coord_scale
            * (
                coordinate_loss
                + width_height_loss
            )
            + object_confidence_loss
            + self.noobject_scale
            * noobject_confidence_loss
            + classification_loss
        )
```

### 판정

`DIRECT SETTINGS / 예상코드`

공식 Darknet은 이 로직을 C detection layer에서 수행하지만, 위 코드는 Equation (3)을 읽기 쉬운 형태로 분리한 예상 구현입니다.

```
def yolov1_learning_rate(
    epoch: int,
    warmup_epochs: int = 5
) -> float:
    if epoch < warmup_epochs:
        progress = (
            epoch
            / max(
                warmup_epochs - 1,
                1
            )
        )

        return (
            1e-3
            + progress
            * (1e-2 - 1e-3)

    if epoch < 105:
        return 1e-3

    return 1e-4
```

## 61. Error Analysis 기준

### 논문 텍스트

- Correct: 올바른 class, `IoU > .5`
- Localization: 올바른 class, `.1 < IoU < .5`
- Similar: 유사 class, `IoU > .1`
- Other: 잘못된 class, `IoU > .1`
- Background: 모든 object와 `IoU < .1`

↓

### 대응 코드

공식 저장소에는 이 다섯 오류 유형을 동일하게 분류하는 Hoiem error-analysis 구현이 없습니다.

### (예상코드)

```
def categorize_detection_error(
    predicted_class,
    ground_truth_class,
    maximum_iou,
    similar_classes
):
    if (
        predicted_class
        == ground_truth_class
        and maximum_iou > 0.5
    ):
        return "correct"

    if (
        predicted_class
        == ground_truth_class
        and 0.1 < maximum_iou <= 0.5
    ):
        return "localization"

    if (
        ground_truth_class
        in similar_classes.get(
            predicted_class,
            set()
        )
        and maximum_iou > 0.1
    ):
        return "similar"

    if maximum_iou > 0.1:
        return "other"

    return "background"
```

```
def rescore_fast_rcnn_with_yolo(
    fast_rcnn_detections,
    yolo_detections,
    overlap_threshold=0.5
):
    rescored = []

    for rcnn_detection in fast_rcnn_detections:
        best_overlap = 0.0
        best_yolo_score = 0.0

        for yolo_detection in yolo_detections:
            if (
                yolo_detection["class_id"]
                != rcnn_detection["class_id"]
            ):
                continue

            overlap = box_iou(
                rcnn_detection["box"],
                yolo_detection["box"]
            )

            if overlap > best_overlap:
                best_overlap = overlap
                best_yolo_score = (
                    yolo_detection["score"]
                )

        new_score = rcnn_detection["score"]

        if best_overlap >= overlap_threshold:
            new_score += (
                best_yolo_score
                * best_overlap
            )

        rescored.append({
            **rcnn_detection,
            "score": new_score
        })

    return rescored
```

### (예상코드)

```
import numpy as np

def precision_recall_f1(
    true_positives,
    false_positives,
    total_ground_truth
):
    cumulative_tp = np.cumsum(
        true_positives
    )

    cumulative_fp = np.cumsum(
        false_positives
    )

    precision = (
        cumulative_tp
        / np.maximum(
            cumulative_tp
            + cumulative_fp,
            1
        )
    )

    recall = (
        cumulative_tp
        / max(
            total_ground_truth,
            1
        )
    )

    f1 = (
        2
        * precision
        * recall
        / np.maximum(
            precision + recall,
            1e-12
        )
    )

    return (
        precision,
        recall,
        f1,
        float(f1.max())
    )
```
